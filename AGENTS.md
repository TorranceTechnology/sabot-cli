# sabot-cli

Developer tooling for the Sabot rules engine: a rules-graph schema, command-line tools over that graph, and agent skills. Python, managed with `uv`.

## Rules

- This repository is public. Commit no ruleset text, card text, card art or other third-party material, and name no specific commercial game in tracked files. Test fixtures use invented rules.
- Rule paraphrases in any example are original wording.
- No code copied, translated or closely paraphrased from another project, whatever its licence. Design ideas with citation in the pull request description are fine.
- The tools read and write Markdown and never load the engine.
- A tool that refuses input has a probe test that plants the refusal.
- Sign off every commit (`git commit -s`). Branch from `main`.
- Keep the README current with setup, run and test commands.
